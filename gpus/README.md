# GPUs

Pasta raiz para documentação e recursos relacionados a GPUs, organizada por fabricante.

Cada subpasta de fabricante deve conter um README com:

- Visão geral dos modelos suportados
- Instruções para drivers e instalação
- Exemplos de uso e benchmarks
- Notas sobre compatibilidade com frameworks (CUDA, ROCm, OpenCL, Vulkan)
