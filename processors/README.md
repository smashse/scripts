# Processadores

Pasta raiz para documentação e recursos relacionados a processadores (CPUs), organizada por fabricante.

Cada subpasta de fabricante deve conter um README com:

- Visão geral dos modelos suportados
- Instruções para testes e benchmarks
- Links para drivers e ferramentas relevantes
- Exemplo de formato de arquivo para listar modelos (p.ex. MODELS.md)
