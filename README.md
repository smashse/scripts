# Estrutura do repositório: Processadores e GPUs por fabricante

Esta branch adiciona uma estrutura de pastas organizada por fabricantes para processadores e GPUs. Cada pasta de fabricante contém um README com orientações sobre como adicionar informações sobre modelos, benchmarks e notas de compatibilidade.

Diretórios criados:

- processors/
  - Intel/
  - AMD/
  - ARM/
  - Other/

- gpus/
  - NVIDIA/
  - AMD/
  - Intel/
  - Other/

Use estas pastas para documentar modelos, instruções de compatibilidade, scripts de benchmark e qualquer outro recurso relacionado aos dispositivos.
